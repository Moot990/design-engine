# Design Engine

Project setup for Design Engine. The full project implementation and GitHub Actions workflows will be added after the project brief.

## Development

Work on `main`, use clear commit messages, and push after every major step.

Store secrets only in GitHub Actions repository secrets under **Settings → Secrets and variables → Actions**. Never commit credentials or tokens.

The `.github/workflows/` folder is ready for workflow files. No workflow runs until a workflow YAML file is added.
